HNG Internship Stage 1: Frontend Profile Card & Multi-Page Application

This repository contains the solution for the HNG Internship Stage 1 Frontend Task which is built off of stage 0. The project is built using only Semantic HTML, Pure CSS, and Vanilla JavaScript, focusing on accessibility, responsiveness, and adhering to strict automated testing requirements.

🚀 Project Overview

The core component is a Profile Card, which has been expanded into a small multi-page application using three self-contained HTML files:

index.html: The primary Profile Card component, featuring the required real-time UTC millisecond clock.

about.html: A reflective "About Me" page with personal goals and thoughts.

contact.html: A functional contact form with client-side validation.

Core Requirements Fulfilled

Technology Stack: Only HTML, pure CSS (embedded in <style> tags), and Vanilla JavaScript (embedded in <script> tags) were used. No frameworks or external libraries were imported.

Accessibility (A11Y): Semantic HTML tags are used throughout, ensuring keyboard navigability and screen reader compatibility.

Responsiveness: The layout is fully responsive, adapting cleanly for mobile, tablet, and desktop viewports using CSS media queries and Flexbox/Grid techniques.

Testability: Every required visible content element includes the exact specified data-testid attribute for automated testing.
